How it works: code does the math, AI reads the language


The AI is used only where code can't do the job. Everything else is plain, testable Python.






Errors it plans for
    

  • API down or rate-limited: retries with backoff, cached responses
    • 

  • Bad or renamed fields: Pydantic validation, rejected rows kept with the reason
    • 

  • Duplicates: upsert on platform + market id
    • 

  • Stale prices: pairs older than a set number of minutes are skipped
    • 

  • Broken AI JSON: one retry with the error, then human review
    • 

  • Made-up quotes: every quote checked against the source text
    • 



Guardrails
    

  • Read-only: no wallets, no trading keys, no orders
    • 

  • Public market data only, within each platform's terms
    • 

  • Unclear or missing rules are rated high risk, never guessed
    • 

  • Every warning shows the exact rule text behind it
    • 

  • Prompt version and model saved with every result
    •
