How it works: code does the math, you and the AI read the language

Why most "gaps" are fake

  • The two titles look alike but ask different things ("visit" vs "arrested")
  • Different closing dates, thresholds or data sources
  • Only a few contracts at the quoted price
  • Fees: up to 1.75¢ per contract on each side near 50¢

What a real one looks like

  • Same wording, same date, prices within a few cents
  • No warnings and no one-sided words
  • Rules name the same source and deadline
  • Edge survives at the size you want
  • You've pressed "Same question"

Guardrails

  • Read-only: no keys, no wallets, no orders
  • Every AI quote is checked against the source text
  • Unclear rules are rated high risk, never guessed
  • Paper fills walk the real order book

ArbLens. Python, FastAPI, SQLite, Kalshi Trade API v2, Polymarket Gamma and CLOB APIs, optional Claude rules check with Pydantic validation. Data is public market data; nothing here places a trade.
